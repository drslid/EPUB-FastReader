# Comptes retirés du parcours

Le projet utilise désormais uniquement l’espace local du navigateur. Les écrans de compte, le client Supabase et les fichiers de backend de l’itération précédente ont été retirés. Aucune configuration de compte ou d’e-mail n’est nécessaire.

L’ancien lien `#account` ouvre « Ma bibliothèque », qui contient les livres déjà importés. Voir [STORAGE.md](STORAGE.md) pour les données, la migration et les limites entre appareils.
