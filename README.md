## 📚 What Is It?

**EPUB FastReader** is an online tool to convert EPUB files into a "speed reading" format using **Bionic Reading** techniques — helping you read faster and retain more.

Built with:
- JavaScript
- JSZip
- Epub.js
- Tailwind CSS

---

## ✨ Features (Work In Progress)

- 📂 **EPUB File Upload & Conversion** – Just drag, drop, and convert.
- ⚡ **Bionic Reading Style** – Enhances focus and reading speed.
- 🖼️ **Image Handling** – Converts images to base64 for better offline use.
- 📖 **Built-in EPUB Viewer** – Read directly in the browser with a fast, minimalist UI.
